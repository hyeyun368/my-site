# my-site

순수 HTML, CSS, JavaScript로 만든 홍길동의 자기소개 웹사이트입니다.

## 배포 주소

https://내아이디.github.io/my-site/

## 로컬에서 보기

빌드나 설치 과정 없이 바로 열 수 있습니다.

1. 이 저장소를 내려받습니다.
2. 폴더 안의 `index.html`을 더블클릭해 브라우저에서 엽니다.

또는 브라우저 주소창에 파일 경로를 직접 입력해도 됩니다.

```
file:///C:/Users/hyeyu/projects/my-site/index.html
```

## 파일 구성

- `index.html`: 페이지 구조와 내용
- `style.css`: 디자인
- `script.js`: 푸터 연도 표시, 스크롤 효과
